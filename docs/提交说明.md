## 一、一句话概述

**一个 AI，全岗位自主接待**：进线即自动分流（售前 / 售中 / 售后）→ RAG 检索 + 大模型生成 → 秒级回复、无需转接，直接提升 **接待量 / 满意度 / 转化率**（对齐赤兔名品三指标）。

## 二、赛题对齐

| 赛题现状（千牛人工） | 本方案对应 |
|---|---|
| 人工分岗（售前/售中）+ 转接流转 | 意图识别 → `post()` 自动路由 售前/售中/售后，进线即分流 |
| 分流不精准、转接多 | 零转接，AI 全岗位自主接待 |
| 赤兔名品记录接待量/满意度/转化率 | Demo C 三指标对比，AI 实时提升 |
| 多平台（淘系/京东/抖音）规则各异 | 四平台 Adapter + 规则库，话术风格自动切换 |

## 四、快速运行

### 方式一（零安装，评委双击即玩）

直接双击打开 `docs/交互Demo.html` —— 无需 Python / 密钥 / 联网，内置意图识别 + 岗位分流 + 四平台预置话术。

### 方式二（真实大模型生成）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置密钥（复制 .env.example 为 .env 并填入 DEEPSEEK_API_KEY）
#    DEEPSEEK_API_KEY=sk-xxx

# 3. 可视化演示（浏览器自动打开）
streamlit run src/app.py

# 4. 或 HTTP 服务（curl 演示）
uvicorn api:app --app-dir src --reload
```

三个 Demo：**A 话术生成** / **B 智能接待（多轮）** / **C 话术质量对比**。

## 五、技术亮点

- **RAG 检索**：BM25（字符 bigram 中文分词，零外部依赖），Top-K 召回产品知识 + 平台规则。
- **岗位自动分流**：意图识别 → 售前/售中/售后，替代人工分岗与转接。
- **多平台适配**：统一网关 + Adapter 层隔离平台差异，话术风格自动切换（京东/天猫/抖音/拼多多）。
- **可解释**：每次回复输出「命中产品 + 意图 + 岗位」，链路透明。
- **可扩展**：知识库改 JSON 即更新，零训练成本；检索可平滑升级向量检索。

> ⚠️ `.env`（含真实密钥）**未包含**在提交包内，请勿上传公开仓库。
