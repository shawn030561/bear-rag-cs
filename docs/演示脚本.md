# 演示视频脚本（约 3 分钟）

> 面向小熊电器黑客松评审。核心叙事：**替代千牛人工「分岗 + 分流 + 转接」的全自主接待**。
> 演示主体用 Streamlit（`streamlit run src/app.py`），架构页用 `docs/方案PPT.html` 或 PPT 截图。

---

## 镜头 0 · 开场（0:00–0:15）

**画面**：PPT 封面页（小熊电器 AI 智能客服）。
**台词**：

> 各位评委好，我们是小熊电器 AI 智能客服。它用大模型 RAG 融合产品知识库和多平台规则，把人工客服「分岗、分流、转接」的流程，替换成一个 AI 全岗位自主接待。

---

## 镜头 1 · Demo A 话术生成（0:15–0:55）

**画面**：Streamlit 界面，切到「🔤 话术生成 Demo A」。

| 步骤 | 操作 | 台词 |
|---|---|---|
| 1 | 左侧「接待平台」选 **京东** | 先看话术生成。选京东。 |
| 2 | 输入「这款按摩器和SKG比有什么优势？」点生成 | 买家问一个典型对比问题。 |
| 3 | 指向「检索到的产品知识」展开区 | 注意，AI 不是直接编，是先 **BM25 检索**命中产品卖点，再做**检索增强生成**，所以话术有据可依。 |
| 4 | 指向输出话术，圈出三点 | 输出同时具备**卖点**（揉捏+热敷）、**对比**（比 SKG 便宜 30%）、**促单**（满减 + 次日达）三要素。 |
| 5 | 指向底部「岗位：售前 · 意图：对比」 | 而且自动识别意图、**分流到售前岗位**。 |

---

## 镜头 2 · Demo B 智能接待 + 岗位分流（0:55–1:55）

**画面**：切到「💬 智能接待 Demo B」。

| 步骤 | 操作 | 台词 |
|---|---|---|
| 1 | 切平台到「抖音」（体现多平台） | 换到抖音，看多轮接待。 |
| 2 | 第 1 轮输入「想给爸妈买个养生壶」 | 买家进线，AI 主动**推荐 + 挖需**，而不是丢一句「亲你好」。 |
| 3 | 指向「岗位：售前 · 意图：推荐」 | 自动分流到**售前**。 |
| 4 | 第 2 轮输入「能预约吗？」 | 追问参数，AI **讲解**。 |
| 5 | 第 3 轮输入「现在下单有优惠吗？」 | 有购买意向，AI 切到**促单**。 |
| 6 | 指向「岗位：售中 · 意图：优惠」 | 注意岗位从**售前自动切换到了售中**——这就是替代人工分岗：进线即分流，无需转接。 |
| 7 | 小结 | 如果用户问售后，它会自动切到售后岗位。全程没有一次转接。 |

## 镜头 3 · Demo C 话术对比（1:55–2:30）

**画面**：切到「📊 对比数据 Demo C」，点「批量生成」。

| 步骤 | 操作 | 台词 |
|---|---|---|
| 1 | 点批量生成，等待完成 | 最后看数据对比。用 10 条真实样例，AI 话术和人工话术并排。 |
| 2 | 指向并排对比 | 左边人工、右边 AI，AI 话术卖点更全、风格更贴合平台。 |
| 3 | 对应赤兔名品三指标 | 对齐赛题里的赤兔名品三指标——**接待量**（AI 7×24 不设上限）、**满意度**（话术标准化稳定）、**转化率**（秒回 + 促单、无转接流失）。 |

## 镜头 4 · 技术架构 + 收尾（2:30–3:00）

**画面**：切到 `方案PPT.html` 第 6 页（技术架构）和第 4 页（千牛工作流对照）。

| 步骤 | 操作 | 台词 |
|---|---|---|
| 1 | 指向五层架构图 | 技术上分五层：数据层（产品知识库 + 平台规则）→ 检索层（BM25）→ 生成层（DeepSeek）→ 对话层（意图 + 漏斗）→ 应用层。 |

| 3 | 指向统一网关（第 10 页） | 接入方式也简单：一个统一网关 + 平台适配器，京东/天猫/抖音/拼多多一套代码适配。 |
| 4 | 结束语 | 整个方案零训练成本、改 JSON 即更新。以上，谢谢各位评委。 |

## 备选：无界面时的 curl 演示（1 分钟精简版）

如果没有界面，用终端演示 HTTP 服务同样成立：

```bash
# 启动
uvicorn api:app --app-dir src --reload

# 京东（售前·推荐）
curl -X POST http://127.0.0.1:8000/demo/jd \
  -H "Content-Type: application/json" \
  -d '{"text":"想给爸妈买个养生壶","session_id":"1"}'

# 抖音（售中·优惠）
curl -X POST http://127.0.0.1:8000/demo/douyin \
  -H "Content-Type: application/json" \
  -d '{"text":"现在下单有优惠吗","session_id":"2"}'
```

返回体里自带 `intent`（意图）和 `post`（岗位），现场直接指给评委看即可。
